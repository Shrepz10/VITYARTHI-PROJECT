🧠 Word Quest Game

Word Quest is an interactive word-based quiz game where players test and improve their vocabulary by answering fun and challenging word-related questions.

Challenge yourself, learn new words, and see how high you can score! 🎮📚

🎮 Features

🧠 Test your vocabulary

📖 Learn new and interesting words

🏆 Earn points for correct answers

🎯 Complete different word quests

📊 Track your score and progress

❤️ Track lives/attempts

💻 Simple and interactive user interface

📱 Responsive design for different screen sizes

🛠️ Technologies Used

HTML5

CSS3

JavaScript
